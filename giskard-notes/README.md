# Giskard - AI公平性与鲁棒性测试

## 核心概念（文档学习，无需实践）

### 偏见检测（Bias Detection）
构造对照组，只改变敏感属性（性别、种族、年龄），检测模型是否差异化对待。

### 鲁棒性测试（Robustness）
对输入做微小扰动（错别字、同义词、语序），验证输出稳定性。

### 数据泄露检测（Data Leakage）
检测模型是否会泄露训练数据中的敏感信息。

## 与其他工具的定位区别

| 工具 | 测什么 | 核心问题 |
|------|--------|---------|
| DeepEval | 输出质量 | 答案对不对、有没有幻觉 |
| Promptfoo | 安全性 | 能不能被攻击、会不会越狱 |
| Giskard | 公平性+稳定性 | 有没有歧视、输入变一点会不会崩 |
