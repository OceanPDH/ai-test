# API 限流与配额

## 速率限制
- 免费版：10 请求/分钟，1,000 请求/月
- 专业版：100 请求/分钟，50,000 请求/月
- 企业版：1,000 请求/分钟，无月度上限

## 超限处理
- 达到分钟级限流时，返回 HTTP 429，建议实现指数退避重试
- 达到月度配额时，按 $0.001/次 自动扣费（需提前开启超量计费）
- 未开启超量计费则请求直接拒绝，返回 HTTP 429

## 请求大小限制
- 单次请求 body 最大 10MB
- 单次响应最大 5MB
- 批量请求最多 100 条/次

## 监控配额使用
- 控制台「使用量」页面实时查看
- 可设置邮件告警（80%、90%、100% 时触发）
- 提供 /v1/usage API 端点查询当前用量
