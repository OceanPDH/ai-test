# 安全与合规

## 数据加密
- 传输中：全程 TLS 1.3 加密
- 静态数据：AES-256 加密存储
- API 密钥：加盐哈希后存储，平台无法还原明文

## 访问控制
- 支持 API 密钥级别的权限控制（只读、读写、管理员）
- 支持 IP 白名单
- 支持 SSO（SAML 2.0 / OIDC），企业版功能
- 多因素认证（MFA）强制启用

## 合规认证
- SOC 2 Type II 认证
- ISO 27001 认证
- GDPR 合规
- 中国区数据存储在境内服务器，符合数据本地化要求

## 数据隔离
- 不同租户数据严格隔离
- 企业版支持独立部署，数据不与其他租户共享
- 员工访问客户数据需审批留痕
